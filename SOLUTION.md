# Решение

## Сколько заняло

Около 1 часа.

## Что сделано и что не успел

Сделан экран матчей: загрузка, фильтр, карточки, обновление, избранное.

## Решения

**Фильтр.** «Предстоящие» — только `scheduled`. «Завершённые» — только `finished`. `live` и `postponed` остаются во «Все»: живой матч уже идёт, перенесённый ещё не назначен заново.

**Данные.** `startsAt` может быть `null` — показываем «Время не назначено», без падения `Date`. `score` бывает `null`; `0:0` при этом показываем, потому что это валидный счёт, а не отсутствие. Дата с суффиксом `Z` форматируется через `toLocaleString` без `timeZone`, то есть в поясе устройства. Ответ — объект `{ round, matches }`, не массив.

## Баги из части 2

1. Звёздочки: `Boolean(indexOf(id))` даёт `true` для `-1` (матча нет в списке) и `false` для индекса `0`. Плюс `push`/`splice` меняли тот же массив, React не видел обновление — отсюда «горят все» и хаотичные нажатия. Исправил на `includes` и новый массив в `setFavorites`.
2. «Обновлено N сек назад»: интервал захватывал начальный `seconds` и всегда ставил `1`, проп `since` не использовался, таймер не сбрасывался. Считаю разницу с `since` каждую секунду и перезапускаю эффект при новой дате.

## Как я использовал ИИ

Cursor. Проверил в браузере: фильтры, `0:0`, перенесённый матч без времени, повтор загрузки, звёздочки и счётчик «обновлено».
